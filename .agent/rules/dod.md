# Path Logic: Definition of Done (DoD)

- [ ] No framework-specific imports in @pathlogic/core.
- [ ] Every storage write is wrapped in the EncryptionPort.
- [ ] Every new or modified feature includes domain unit specs (\*.spec.ts) with full branch coverage.
- [ ] Every new or modified UI component/page has a complete Storybook story (\*.stories.ts) with play interaction testing and a11y checks.
- [ ] Every Storybook play interaction test has a corresponding headless CI spec (\*.stories.spec.ts).
- [ ] Vitest suite passes for the core domain.
- [ ] All static analysis, type checking, and formatting pass cleanly.
